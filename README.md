# 🌿 Herbarium Classification using Deep Learning

A deep learning project focused on image classification of herbarium plant specimens using Convolutional Neural Networks (CNNs).

## 📌 Overview

Herbarium collections contain preserved plant samples used for botanical research and biodiversity studies. This project explores how computer vision and deep learning can automate the classification of herbarium images.

The objective is to build a robust image classification pipeline capable of distinguishing between multiple plant categories from digitized herbarium sheets.
